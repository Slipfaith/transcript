# Локальный транскрибатор лекций

Расшифровка лекций на своём ноутбуке с NVIDIA GPU через faster-whisper.
Аудио никуда не отправляется. Бриф: [lecture-transcriber-brief.md](lecture-transcriber-brief.md).

Готово: установка, проверка окружения, CLI, окно на PySide6 и разметка спикеров.

## Окно

Запуск: двойной щелчок по **`app.bat`**. Файлы и папки можно сразу перетащить на `app.bat`,
в окно или в пунктирную зону (щелчок по ней открывает выбор файлов).

- Внизу выбираются модель, язык, устройство, форматы, папка для результатов и термины
  (подсказки к опциям во всплывающих подсказках).
- **Начать** расшифровывает очередь по одному файлу. Прогресс показывает позицию в записи,
  скорость (×realtime) и сколько осталось.
- **Остановить** прерывает работу после текущего фрагмента, сделанное сохраняется в `*.partial.*`.
- **Журнал** (Ctrl+L) показывает распознанный текст по ходу и сообщения об ошибках.
- Двойной щелчок по готовому файлу открывает `.txt`. **Открыть папку с результатом**
  открывает Проводник с выделенным файлом.
- В строке состояния справа видно, какую видеокарту нашёл `nvidia-smi`.
- **Сервис → Проверить окружение** запускает `check_env.py` и выводит результат в журнал.
- **Вид → Тёмная тема.** Настройки и размер окна запоминаются между запусками.

На CPU окно перед стартом переспрашивает: молча на процессор оно не переключается.

## Разметка спикеров

Галочка **«Разметить спикеров»** в окне или `--speakers` в командной строке. Реплики
подписываются так: кто говорит больше всех — **Лектор**, остальные — **Слушатель 1**,
**Слушатель 2** и т. д.

```
Лектор: Нет, собственные значения определены только для квадратных матриц.

Слушатель 1: Понятно, спасибо. А это будет на экзамене?
```

В `.txt` при смене спикера начинается новый абзац с подписью, в `.md` подпись выделена
жирным, в `.srt` она стоит в начале реплики. Если в записи один голос, подписей не будет.

Как это работает: для каждого фрагмента считается «отпечаток голоса» (модель WeSpeaker,
sherpa-onnx), потом похожие отпечатки объединяются. Считается на CPU в отдельном потоке,
пока видеокарта распознаёт речь, поэтому почти не добавляет времени. PyTorch и регистрация
на Hugging Face не нужны. Модель (25 МБ) скачивается в `models\diarization` при установке.

- Если знаете, сколько голосов в записи, укажите это (**Голосов** в окне,
  `--num-speakers 2` в CLI): разметка будет точнее.
- Если лектора разбивает на нескольких спикеров, увеличьте `--speaker-threshold`
  (например, до 0.45). Если вопросы из зала сливаются с лектором, уменьшите (до 0.25).
  По умолчанию 0.35: значение подобрано на синтетических голосах, его стоит проверить
  на настоящей лекции.
- Спикер определяется на весь фрагмент Whisper. Если вопрос и ответ прозвучали без паузы
  и попали в один фрагмент, он целиком уйдёт одному из них.
- С разметкой файлы пишутся в конце, а не по ходу работы. При остановке сделанное
  сохраняется в `*.partial.*` без подписей.

## Командная строка

Самое простое: **перетащить файлы лекций на `transcribe.bat`**. Результаты появятся рядом
с исходником: `<имя>.txt`, `<имя>.srt`, `<имя>.md`.

Из консоли:

```
transcribe.bat lecture.mp4
transcribe.bat a.m4a b.mkv --model large-v3
transcribe.bat "D:\Лекции\*.mp3" --out-dir transcripts
transcribe.bat lecture.mp3 --prompt "Теорема Гамильтона — Кэли, Коши, Лагранж"
```

| Опция | Что делает |
|---|---|
| `--model` | `large-v3-turbo` (по умолчанию), `large-v3`, `medium`, `small` |
| `--lang` | `ru` (по умолчанию), `en`, ... или `auto` |
| `--out-dir` | папка для результатов вместо «рядом с исходником» |
| `--formats` | например `txt,md`; по умолчанию все три |
| `--prompt` | термины и фамилии из лекции, чтобы они писались правильно |
| `--paragraph-gap` | пауза в секундах для нового абзаца в `.txt` (по умолчанию 2) |
| `--speakers` | разметить спикеров (лектор / слушатели) |
| `--num-speakers` | сколько голосов в записи, если известно |
| `--speaker-threshold` | чувствительность разметки (по умолчанию 0.35) |
| `--show-text` | печатать текст по ходу расшифровки |
| `--overwrite` | переделать уже расшифрованные файлы (иначе они пропускаются) |
| `--no-vad`, `--no-normalize` | не вырезать тишину / не выравнивать громкость |
| `--device cpu` | только для проверки без NVIDIA, очень медленно |

Что на выходе:
- `.txt`: сплошной текст, абзацы по паузам;
- `.srt`: субтитры, границы по словам, открываются в плеере;
- `.md`: шапка (файл, длительность, модель) и строки `[ЧЧ:ММ:СС] текст`, удобно отдавать Claude.

Файлы пишутся по ходу работы. Если прервать (Ctrl+C) или что-то упадёт, сделанная часть
останется в `<имя>.partial.txt` и т. п.

После каждого файла печатается длительность аудио, время обработки и скорость (×realtime).
Всё это пишется в `logs\transcribe.log`.

Подсказка `--prompt` в тесте заметно замедлила работу на CPU, поэтому используйте её, когда
в лекции действительно много терминов.

## Что нужно на ноутбуке заранее

1. **Свежий драйвер NVIDIA** с nvidia.com (GeForce Game Ready или Studio).
   Для RTX 50xx (Blackwell) драйвер должен поддерживать **CUDA 12.8+**.
   Проверка: `nvidia-smi` в консоли, в правом верхнем углу строка `CUDA Version: 12.8` или выше.
   Отдельно ставить CUDA Toolkit **не нужно**.
2. **Python 3.12** (подойдёт 3.10–3.13, 64-bit) с python.org. При установке отметить
   «Add python.exe to PATH».
3. **ffmpeg**: `winget install Gyan.FFmpeg`, потом открыть новую консоль.
4. Интернет при установке: зависимости весят около 1,5 ГБ, модель large-v3-turbo ещё около 1,6 ГБ
   (качается при первом запуске).
5. Ноутбук должен работать от сети.

## Установка

Скопировать папку проекта на ноутбук и запустить двойным щелчком:

```
install.bat
```

Скрипт создаст `.venv`, поставит зависимости и сразу запустит проверку окружения.

## Проверка окружения

```
.venv\Scripts\python.exe check_env.py
```

Что проверяется:
- версия Python;
- наличие ffmpeg;
- GPU по `nvidia-smi`: модель, драйвер, версия CUDA, VRAM, compute capability;
- видит ли CTranslate2 карту и умеет ли float16;
- пробная расшифровка на модели `tiny` прямо на GPU.

Полезные варианты:

```
.venv\Scripts\python.exe check_env.py --model large-v3-turbo
.venv\Scripts\python.exe check_env.py --device cpu
```

Первый прогоняет проверку на рабочей модели и показывает, сколько VRAM она занимает.
Второй проверяет логику без NVIDIA (на целевом ноутбуке он не нужен).

**Если что-то не так, пришлите весь вывод `check_env.py`**: по нему понятно, что чинить.

## Частые проблемы

| Симптом | Что делать |
|---|---|
| `nvidia-smi` не найден | Не стоит драйвер NVIDIA. Установить и перезагрузиться |
| `CUDA Version` ниже 12.8 | Обновить драйвер |
| Ошибка про `cublas64_12.dll` или `cudnn` | `.venv\Scripts\python.exe -m pip install -r requirements.txt` |
| `no kernel image is available` | CTranslate2 не умеет Blackwell. Сначала `.venv\Scripts\python.exe -m pip install -U ctranslate2`, если не помогло: `install.bat fallback` |
| `out of memory` | Закрыть игры и браузер с видео или взять модель поменьше |

## Запасной путь (PyTorch cu128)

Если faster-whisper не заработал на Blackwell:

```
install.bat fallback
```

Ставит PyTorch с CUDA 12.8 (около 3 ГБ). `check_env.py` покажет его отдельным разделом
и проверит, есть ли в сборке поддержка `sm_120`. Расшифровка через этот путь будет добавлена,
если основной не заработает.

## Файлы

- `app.bat`, `app.py`: окно (PySide6)
- `gui/`: главное окно, зона перетаскивания, фоновый поток, темы
- `transcribe.bat`: CLI-запуск, сюда тоже можно перетаскивать файлы
- `transcribe.py`: CLI расшифровки
- `engine.py`: общее ядро для CLI и окна (ffmpeg, модель, прогресс, остановка)
- `diarize.py`: разметка спикеров (sherpa-onnx)
- `models\diarization\`: модель голосов (скачивается сама)
- `outputs.py`: запись `.txt` / `.srt` / `.md`
- `install.bat`: установка в `.venv` и проверка
- `check_env.py`: диагностика окружения
- `gpu_env.py`: пути к DLL CUDA на Windows и опрос `nvidia-smi`
- `requirements.txt`: основные зависимости
- `requirements-fallback.txt`: запасной путь на PyTorch
