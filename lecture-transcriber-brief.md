# Бриф: локальный транскрибатор лекций (Windows + NVIDIA GPU)

## Контекст
Нужна своя замена сервисам вроде zachet.app: расшифровка лекций локально,
без отправки аудио в облако. Конспекты, карточки и тесты потом делаются
по готовой расшифровке в Claude, отдельно от этого инструмента.

## Железо
- Ноутбук на Windows
- **NVIDIA GeForce RTX 5050 Laptop GPU** (Blackwell, 8 ГБ VRAM). На ней всё и считаем
- AMD Radeon 780M (встроенная). **Не использовать**, Whisper нужна CUDA
- Работать от сети. Python должен запускаться на дискретной NVIDIA, а не на iGPU

## Цель
Скрипт или маленькое приложение: подаёшь файл лекции (mp3/m4a/wav/mp4/mkv…),
получаешь расшифровку на русском (язык можно выбрать) в форматах:
- `.txt`: сплошной текст с абзацами
- `.srt`: субтитры с таймкодами
- (опц.) `.md` с таймкодами по сегментам, удобно скармливать Claude

## Технологии
- **faster-whisper** (CTranslate2), основной вариант
- Модель по умолчанию **large-v3-turbo**, на выбор large-v3 / medium / small
- `compute_type="float16"` на GPU. Large-v3 в fp16 занимает около 4–5 ГБ VRAM, в 8 ГБ влезает
- ffmpeg для извлечения и нормализации звука из видео
- VAD-фильтр (`vad_filter=True`), чтобы выкидывать тишину

## Подводный камень: Blackwell
RTX 50-й серии нужны свежий драйвер NVIDIA и **CUDA 12.8+**. Готовые колёса
CTranslate2 и PyTorch могут не поддерживать sm_120.
1. Первым шагом проверить окружение: драйвер (`nvidia-smi`), видна ли карта,
   стартует ли faster-whisper на `device="cuda"`
2. Если CTranslate2 не работает на GPU, **fallback**: PyTorch с CUDA 12.8
   (`--index-url https://download.pytorch.org/whl/cu128`) + `transformers`
   pipeline или `openai-whisper`
3. Если не завелось ни то, ни другое: внятная ошибка и инструкция, что
   обновить. Молча уходить на CPU нельзя (только с явным предупреждением)

## Функциональные требования
- Проверка при старте: какой GPU используется, сколько VRAM, версия CUDA
- Принимает один или несколько файлов (CLI-аргументы или drag-and-drop)
- Прогресс-бар (по длительности аудио)
- Выбор модели и языка (по умолчанию `ru`, плюс автоопределение)
- Длинные файлы (1,5–3 часа) должны обрабатываться без падений
- Результаты кладутся рядом с исходником или в папку `transcripts/`
- Лог времени: длительность аудио, время обработки, скорость (×realtime)

## Этапы
1. **Окружение**: `requirements.txt`, проверка GPU, инструкция по установке (README)
2. **CLI**: `transcribe.py file.mp4 --model large-v3-turbo --lang ru`
3. **(опц.) GUI на PySide6**: окно с drag-and-drop, выбор модели и языка,
   прогресс, кнопка «открыть папку с результатом». Без наложений, нормальный
   resize, тёмная тема по желанию
4. **(опц.)** разметка спикеров (лектор / вопросы из зала)

## Критерии приёмки
- Часовая лекция на large-v3-turbo расшифровывается за минуты, а не за час
- `nvidia-smi` во время работы показывает загрузку RTX 5050
- `.srt` открывается в плеере и синхронизирован со звуком
- Русские термины и имена распознаются приемлемо (проверить на реальной лекции)

## Чего не делать
- Не отправлять аудио ни в какие облачные API
- Не использовать AMD 780M / DirectML в качестве основного пути
